# Attendance Manager

Attendance Manager is a workforce attendance and project management platform designed for construction and field operations. The system enables organizations to manage workers, projects, sites, attendance records, payroll data, and reporting through a centralized web-based administration portal.

## Features

* Multi-project and multi-site management
* Worker onboarding and profile management
* GPS-based attendance monitoring
* Face enrollment and verification support
* Real-time attendance tracking
* Payroll and salary management
* Bulk worker import via Excel
* Attendance and payroll reporting
* Role-based access control
* Audit logging and activity tracking

## System Components

### Admin Dashboard

Web-based portal for administrators and project managers to manage workforce operations.

### Backend Services

REST APIs powering authentication, attendance processing, reporting, payroll calculations, and worker management.
